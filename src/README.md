# Source Code

This directory contains the reusable Python source code for the Secondary Brain Injury machine learning project.

The codebase will include modules for:

- Data preprocessing
- Feature engineering
- Missing-data handling
- Dataset construction
- Model training
- Hyperparameter optimization
- Model evaluation
- Explainability and SHAP analysis
- Reproducible machine learning workflows

Patient-level MIMIC-IV data are not stored in this directory.
